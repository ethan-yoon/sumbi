# Sumbi (숨비)

수면에서 표류하는 다이버의 SOS와 위치를 다이빙 보트와 리조트 관제센터에 바로 보여주는 시스템입니다.

> 이름은 해녀가 물질을 마치고 수면에 올라와 숨을 내쉴 때 내는 소리, "숨비소리"에서 따왔습니다.
> 물 위로 올라와 내 존재를 알리는 신호라는 뜻입니다.

취미 프로젝트로 진행하고 있습니다. 인증된 조난 장비(EPIRB/PLB)가 아니며, 생명 안전 용도로 검증되지 않았습니다.

## 구조

```
[AIS MOB 비콘 (인증 제품)] --VHF 162MHz--> [AIS 수신기: dAISy / RTL-SDR + AIS-catcher] --+
                                                                                       |
                                                                     [Sumbi 게이트웨이 앱] --MQTT--> [관제 서버] --> 관제 화면 / SOS 알림
                                                                                       |
[Sumbi LoRa 태그 (자체 제작, 2차)] --LoRa 920MHz--> [LoRa 컨센트레이터 (2차)] ----------+
```

- **1차 (비상용)**: 인증된 AIS MOB 기기의 신호를 받아 SOS를 판정하고 알림을 보냅니다.
- **2차 (평상시 운영)**: 자체 LoRa 태그로 인원 확인과 다이빙 기록을 남깁니다.
- 게이트웨이는 Raspberry Pi로 만들고, 리조트 옥상 같은 해안 고지대에 설치합니다.

## 로드맵

| 단계 | 목표 | 완료 기준 |
| --- | --- | --- |
| 0 | RTL-SDR + AIS-catcher로 선박 수신 | 주변 선박이 지도에 뜬다 |
| 1 | MOB NMEA 시뮬레이터 + 파싱 + SOS 판정 + 웹 지도 | 가상 다이버가 지도에서 움직인다 |
| 2 | Raspberry Pi 게이트웨이, MQTT, 텔레그램 알림 | SOS가 휴대폰으로 온다 |
| 3 | LoRa 다이버 태그 (nRF52840 + SX1262 + GNSS) | 야외 거리 테스트 성공 |
| 4 | 보홀 알로나 비치 현장 시험 | 수면/SMB 높이 수신 거리 데이터 확보 |

## 저장소 구성 (예정)

```
docs/       설계 문서
gateway/    게이트웨이 앱 (NMEA 파싱, SOS 판정, MQTT)
simulator/  MOB NMEA 시뮬레이터
server/     관제 서버와 웹 화면
tag/        LoRa 다이버 태그 펌웨어 (2차)
```

## 주의

- 직접 만든 송신기로 AIS 주파수에 전파를 내보내지 않습니다. AIS 개발은 NMEA 재생, IQ 파일, 케이블 직결, 인증 기기의 TEST 모드로만 합니다.
- 실제 `MOB ACTIVE` 신호로 시험하지 않습니다.
- AIS-catcher(GPL-3.0)는 별도 프로세스로 실행하고 출력만 받아 씁니다.
